{% comment %} Componente de interruptor de alternancia (toggle switch) según guía de estilos del prototipo. Permite alternar estados booleanos tanto en formularios Django como ejecutando funciones JavaScript. Parámetros disponibles: - id: Identificador único del input (recomendado para asociar con funciones JS o label) - name: Nombre del campo enviado en formularios - value: Valor cuando está marcado (predeterminado: 'true') - checked: Booleano para inicializar activado (true | false) - label: Texto descriptivo de la opción en sentence case - onchange: Código o función JS a ejecutar al cambiar de estado (ej. "miFuncion(this.checked)") - onclick: Código o función JS adicional al hacer clic (opcional) - disabled: Booleano para deshabilitar el interruptor (opcional) - class: Clases CSS complementarias para el contenedor

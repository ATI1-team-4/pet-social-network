# Petly - Red social para mascotas

¡Bienvenido a **Petly**, la aplicación web diseñada para conectar a la comunidad de amantes de los animales!

### 📝 Visión del producto
Crear una plataforma digital que conecte a los amantes de los animales o dueños y sus mascotas, con otras personas de gustos similares, buscando interactuar para socializar o informarse para gestionar intereses.

### 🎯 Grupo objetivo
El sistema está orientado a satisfacer las necesidades de:
* **Amantes de las mascotas** y dueños que buscan expandir su círculo social.
* **Dueños de mascotas** interesados en buscarle pareja a sus compañeros animales.
* **Personas interesadas** en dar en adopción de manera responsable o en adoptar una nueva mascota.
